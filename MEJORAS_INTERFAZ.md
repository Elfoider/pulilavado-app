# Caja y ayudas — 1.5.1

- Las explicaciones de Reportes, Caja, productos, catálogo, sobres y configuración se consultan mediante botones de ayuda. Los globos se abren con clic, toque o teclado; pueden cerrarse con Escape o el botón de cierre. Se colocan dentro de la pantalla, también en móvil. Los errores y las confirmaciones importantes siguen visibles.
- Los accesos entre secciones usan botones con iconos, incluido el de caja registradora para Caja.
- Caja muestra primero los saldos de la jornada seleccionada: efectivo esperado, efectivo a guardar y saldos digitales. Los movimientos se eligen con accesos rápidos Gasto, Retiro / pago, Vale e Ingreso. Se conserva el selector de tipo y la selección obligatoria de lavador para vales.
- El arqueo y cierre se despliega cuando se necesita. Conserva el conteo, diferencia y confirmación de cierre. Al consultar una jornada cerrada se muestran sus datos y no el formulario para mover dinero de otra caja.
- Los campos numéricos de precio por vehículo, cantidad de productos y datos numéricos del inventario conservan el texto vacío mientras se edita. Un cero escrito explícitamente sigue siendo válido donde se admite. Se mantienen las restricciones de cantidad y monto al guardar. Los campos que ya guardaban texto temporal, como montos de Caja y comisiones, siguen permitiendo borrarlos.

No se modifican movimientos, saldos, comisiones ni datos históricos como parte de este cambio de interfaz.
